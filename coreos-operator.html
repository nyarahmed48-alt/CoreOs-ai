Where this data lives

      

        

          Your OpenRouter key and each site's admin token are held in this browser's storage,
          on this machine. They are never written into the file, so sending someone this file
          sends them no credential — but anyone using this browser can read them back. Treat the
          file the way you treat the tokens.
        

        

          A site showing “unreachable” needs the CORS headers from
          netlify/lib/cors.ts deployed. A browser refuses a cross-origin call before
          it is ever sent, so until that is live the console can only watch sites, not control them.
