Where this lives

      

        
Your key and each system's admin token are in this browser's
          storage, on this machine. They are never written into the file — sending someone this file sends them
          no credential — but anyone using this browser can read them back.

        

          A system showing “unreachable” needs the CORS headers from netlify/lib/cors.ts
          deployed. A browser refuses a cross-origin call before it is sent, so until that is live the console
          can only watch, not fix.
